# MetaSkillGroup Corporate Header

A responsive corporate website experience featuring a contact top bar, sticky navigation, animated dropdown menus, a mobile navigation drawer, and an interactive quote request modal.

## Live Demo
https://chipper-lebkuchen-52ae1d.netlify.app/

## Source Code
https://github.com/dy8800779-commits/msg-corporate-header

## Built With
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Manrope
- Font Awesome 6.7.2

## Features
- Responsive corporate header and navigation
- Contact top bar that hides on scroll
- Sticky navigation with scroll shadow
- Services and Industries dropdown menus
- Mobile navigation drawer with overlay
- Quote request modal with Escape-key close and focus management
- Client-side form validation and demo success feedback
- Scroll reveal animations
- Responsive desktop, tablet, and mobile layouts

## Dependencies
- Google Fonts (Manrope): https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700;800&display=swap
- Font Awesome 6.7.2: https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.7.2/css/all.min.css

## Setup
Keep `index.html`, `style.css`, and `script.js` in the same folder, then open `index.html` in a browser or deploy the folder as a static site.

## Important Note
The quote and contact forms currently perform client-side validation and display demo feedback only. Connect a form backend or service to receive real submissions. Replace the sample phone number, email address, and social links with approved business details before production use.

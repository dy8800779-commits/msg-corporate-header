
# MetaSkillGroup Corporate Header

A professional and responsive business website header built using HTML5, CSS3 and Vanilla JavaScript.

## Features

- Professional top contact bar
- Sticky navigation header
- Animated Services and Industries dropdowns
- Responsive mobile navigation drawer
- Quote request modal
- Form validation
- Keyboard accessibility
- Responsive design

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts - Manrope
- Font Awesome 6
